# Finexa - Backend

Backend da **Finexa**, uma aplicação voltada para gerenciamento e organização financeira.

Este projeto está sendo desenvolvido utilizando **Java** e **Spring Boot**, seguindo uma arquitetura organizada em camadas 
para facilitar a manutenção, evolução e escalabilidade da aplicação.

-d--

## 🚀 Tecnologias

- Java
- Spring Boot
- Maven
- Spring Data JPA
- Spring Security
- MySQL
- REST API

---
